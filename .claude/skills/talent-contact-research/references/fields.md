# research_results.csv の列と記入基準

1人1行。同じ人を再調査したら新しい行を足す（ツールは最新日付の行を使う。30日より古い行は使わない）。
空欄は「確認できなかった」の意味。分からないものを埋めない。

| 列 | 記入値 | 基準 |
|---|---|---|
| `talent_id` | research_targets の値 | 必須（`x_handle` だけでも照合はできる） |
| `x_handle` | `@なし` の小文字 | research_targets の値 |
| `display_name` | 表示名 | 見たまま |
| `researched_at_jst` | `2026-09-27` | 調べた日 |
| `researcher` | 作業者名 | 例: `codex-macmini`、`claude-mbp` |
| `account_status` | `存在` / `凍結` / `削除` / `鍵` / `見つからない` | 存在以外は送付対象から外れる |
| `last_post_date` | `2026-09-20` | 固定投稿を除く最新投稿（リポストは除く） |
| `activity_status` | `活動中` / `休止・引退` / `不明` | 30日以内に投稿あり→活動中。休止・引退・卒業の告知あり、または90日以上投稿なし→休止・引退。それ以外→不明 |
| `is_individual` | `yes` / `no` / `unknown` | 事務所・企業・グループ所属の記載あり→no。個人勢と明記、または所属記載なし＋本人運営が明らか→yes |
| `is_japanese_activity` | `yes` / `no` / `unknown` | プロフィールと最近の投稿・配信が主に日本語→yes |
| `dm_open` | `yes` / `no` / `unknown` | プロフィールに「メッセージ」ボタン（封筒アイコン）が表示→yes、無い→no。**クリックしない** |
| `dm_checked_as` | `@kocho_kurono` など | DM確認に使ったログイン中のアカウント |
| `x_followers` | `5200` / `1.2万` | プロフィールの表示 |
| `youtube_subscribers` | `3430` / `1.2万` | チャンネルの表示。非公開なら空欄 |
| `inquiry_policy` | 下表 | お仕事依頼の受付方針 |
| `inquiry_evidence` | 根拠の文言そのまま | 例:「お仕事のご依頼はDMまで」＋どこに書いてあったか（プロフ／固定投稿／lit.link） |
| `contact_email` | 公開されているアドレス | 本人または所属事務所の公式ページにあるものだけ。「☆を@に」等の置換指示がある場合のみ置換 |
| `email_source_url` | そのアドレスが載っていたURL | 必須（`contact_email` を書いたら） |
| `contact_form_url` | 問い合わせフォームのURL | 公式のもの |
| `agency` | 事務所名 | 所属がある場合 |
| `notes` | 自由記述 | 用途限定窓口、YouTube の非表示メール、迷った点など |

## inquiry_policy の値

| 値 | 付ける条件 | ツールでの扱い |
|---|---|---|
| `DM可` | 「お仕事依頼はDMへ」「案件DMで受付」など、DMで依頼を受ける旨の記載 | オプトイン未記録を解消。DMで送付 |
| `メール可` | 依頼の連絡先としてメールが明記されている | オプトイン未記録を解消。**メールで送付**（DMは使わない） |
| `フォーム可` | 依頼の連絡先としてフォームが明記されている | オプトイン未記録を解消。フォームで送付 |
| `依頼お断り` | 「依頼受付停止」「案件お断り」「DMは返信しません」など | 送付対象から外す |
| `記載なし` | 依頼の受付について何も書いていない | オプトイン未記録は解消しない（保留のまま） |

- 窓口が複数あるときは、本人が「こちらへ」と指定している方を選ぶ。指定がなければ `DM可` を優先し、メール・フォームも各列に書いておく
- 所属事務所の窓口しか無い場合は `is_individual=no` になり、今の条件では送付対象外（記録は残す）
- 用途限定の窓口（イラスト依頼専用・ボイス販売・切り抜き報告・質問箱）は `記載なし` 扱い。notes に書く
