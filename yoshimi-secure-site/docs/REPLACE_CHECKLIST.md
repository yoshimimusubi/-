# 公開前に差し替える項目

現行サイト（yoshimimusubi.com）は作成時（2026-10-31）に中身を確認できなかったため、
前回のリニューアル案で分かっていた情報（メンバー 5 名・発信テーマ・活動内容・発信方針）以外は仮の内容です。
画面上では【】の部分が黄色く表示されます。`grep -rn "【" src` で一覧を出せます。

## 必ず差し替える

| ファイル | 今の内容 | 直すもの |
|---|---|---|
| `src/data/site.ts` の `COMPANY` | 代表者・設立・所在地が【】 | 正式な情報（所在地を番地まで出すかも決める） |
| `src/data/site.ts` の `COMPANY_ACCOUNTS` | 空 | 会社の公式 SNS アカウント（なりすまし対策の一覧に出る） |
| `wrangler.jsonc` の `MAIL_TO`・`destination_address` | `contact-inbox@example.com` | Email Routing で確認済みの受信用アドレス |
| `src/pages/contact/index.astro` | 返信の目安【○営業日以内】、JavaScript なしの代替連絡先【】 | 実際の運用に合わせた文言 |
| `src/pages/privacy.astro` | 代表者・所在地・保存期間・制定日が【】 | 正式な内容。全体を専門家に確認してもらう |
| `src/content/members/*.md` の `links` | 胡蝶くろの・宇迦元まりのの X だけ | ほかのメンバーの X・YouTube |
| `src/content/members/hakui-yui.md` | `kana`（よみがな）なし | 正しい読み |
| `src/content/news/site-renewal.md` | 公開日 2026-11-01 | 実際の公開日 |

## 確認してほしい（仮で書いた内容）

| 場所 | 仮の内容 | 確認ポイント |
|---|---|---|
| トップのヒーロー | 「ケアと暮らしに、やさしい声を。」 | 会社として使っている言葉があれば差し替え |
| トップの「活動」6 項目 | 情報発信、現場へのエール、タイアップ、キャスティング、グッズ、AI を取り入れた運営 | 公開してよい事業か |
| トップの「発信で大切にしていること」 | X での発信方針をもとに作文 | 外に出してよい表現か |
| メンバーの紹介文 | 発信テーマから作文 | 設定・口調と合っているか |
| メンバーのイメージカラー | 白衣ゆい #4a9cc7／みもり うめ #d9708a／胡蝶くろの #5b4a8b／宇迦元まりの #d98a3d／クロエ・フォリウム #4f8a5b | 公式の色があれば差し替え |
| メンバーのアイコン | 色付きのりんごに頭文字 | 立ち絵・アイコン画像を入れるか（入れる場合は `src/assets/` に置き、Astro の画像最適化を通す） |
| お問い合わせの種別 | お仕事・取材・セキュリティ報告・そのほか | 窓口の分け方 |
| `public/og.png`・`public/icon.png` | 仮のデザインで作成 | ロゴが決まっていれば差し替え |
