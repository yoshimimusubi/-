# 公開前に差し替える項目

現行サイト（yoshimimusubi.com）は作成時点（2026-10-27）で中身を確認できなかったため、
わかっている情報（メンバー 5 名と発信テーマ、発信方針、活動内容の一部）以外は仮の内容です。
どれも管理画面か AI への依頼で直せます（例:「会社概要の代表者を〇〇にして」）。

## 必ず差し替える

| 場所 | 今の内容 | 直すもの |
|---|---|---|
| 会社概要（`/company`）の表 | 社名「ヨシミムスビ【正式名称を記入】」、代表者・設立・所在地が【記入してください】 | 正式な社名・代表者・設立年月・所在地 |
| お問い合わせ（`/contact`） | メールのリンクが `contact@example.com`（仮） | 実際の窓口のメールアドレス、またはフォームプラグインで作ったフォームに置き換え |
| メンバー 5 名の「ひとこと」 | 【ひとことを記入】 | 各メンバーのキャッチコピー（空にすれば表示されない） |
| メンバーの X・YouTube | 胡蝶くろの・宇迦元まりのの X だけ設定済み | 白衣ゆい・みもり うめ・クロエ・フォリウムの X、全員の YouTube |
| 白衣ゆいのよみがな | 空 | 正しい読み（「はくい」かどうか未確認のため空にしてある） |

## 確認してほしい（仮で書いた内容）

| 場所 | 仮で書いた内容 | 確認ポイント |
|---|---|---|
| サイトのキャッチコピー（設定 › タグライン） | 「ケアと暮らしを、キャラクターでむすぶ。」 | 会社として使っている言葉があれば差し替え |
| トップのヒーロー | 「ケアと暮らしに、やさしい声を。」と説明文 | 「あっぷるぐみ」がプロジェクト名として正しいか |
| トップの「活動」6 項目 | 情報発信、現場へのエール、タイアップ、キャスティング、グッズ・コンテンツ制作、AI を取り入れた運営 | 公開してよい事業か、名前の出し方 |
| トップの「発信で大切にしていること」 | X リプライ運用の方針（断定しない・現場への敬意など）をもとに作文 | 外に出してよい表現か |
| FAQ | 依頼の窓口、医療相談は受けない、応援メッセージの送り先 | 方針と合っているか |
| メンバーの紹介文・プロフィール | 発信テーマから作文した 2 段落 | 設定・口調と合っているか |
| メンバーのイメージカラー | 白衣ゆい #4a9cc7／みもり うめ #d9708a／胡蝶くろの #5b4a8b／宇迦元まりの #d98a3d／クロエ・フォリウム #4f8a5b | 公式の色があれば差し替え |
| 会社概要の「事業内容」 | 活動 4 行 | 登記上・公式の事業内容 |
| お知らせ「公式サイトをリニューアルしました」 | 公開日は初回起動日 | 公開日に合わせて日付を直す |

## 画像（今は 1 枚も入っていない）

- メンバーの立ち絵・アイコン（なければイメージカラーの丸に頭文字を表示）
- ロゴ（設定 › ロゴ。未設定ならサイト名を文字で表示）
- お知らせのアイキャッチ（任意）
- SNS で共有されたときの画像（設定 › SEO の既定画像）

## 公開の設定

- 独自ドメインを使うか（使うなら `wrangler.jsonc` の `EMDASH_SITE_URL` と `routes`）
- 現行サイトの URL から新サイトへの転送（必要なら管理画面のリダイレクトで設定）
- 現行サイトが WordPress なら、記事を取り込むか（管理画面のインポート機能）
