# AI でサイトを更新する（運用ガイド）

このサイトは、AI エージェントが MCP（Model Context Protocol）という窓口からサイトを読み書きできます。
PC では Claude Code、スマホでは Claude アプリから、話しかけるだけで更新できます。

**基本ルール: AI は下書きまで。公開は人が管理画面かプレビューで確かめてから。**
EmDash の MCP は、作ったコンテンツを最初は「下書き」で保存するので、このルールは仕組みとしても守られます。

## 1. つなぐ（最初の 1 回だけ）

前提: サイトが公開済みで、管理画面（`/_emdash/admin`）に管理者を作り、パスキーを登録してあること。
以下の `<公開URL>` は `https://yoshimi-site.<アカウント名>.workers.dev` や独自ドメインに置き換えます。

### PC（Claude Code）

```bash
claude mcp add --transport http yoshimi-site <公開URL>/_emdash/api/mcp
```

初めて使うときにブラウザが開くので、パスキーでログインして接続を許可します（OAuth）。
API キーやトークンをチャットやファイルに貼る必要はありません。

このフォルダには EmDash 公式ドキュメントの MCP（`emdash-docs`）も `.mcp.json` で設定済みです。
コードを直すときに、Claude Code が最新の仕様を調べられます。

### スマホ（Claude アプリ）

1. claude.ai（ブラウザ）で「設定」→「コネクタ」→「カスタムコネクタを追加」
2. 名前を「ヨシミムスビ サイト」、URL を `<公開URL>/_emdash/api/mcp` にして追加
3. 「接続」を押し、開いた画面でパスキーでログインして許可
4. スマホの Claude アプリでチャットを開き、このコネクタを有効にして話しかける

カスタムコネクタが使えるかどうかは、Claude のプランや組織の設定によります。

### ローカル（PC で `npm run dev` 中）

`http://localhost:4321/_emdash/api/mcp` に同じようにつなげます。本番に触らずに試したいときに使います。

## 2. 頼み方の例

### お知らせを追加する（元資料のデモ①にあたるもの）

> 配信の告知をお知らせに追加して。
> タイトルは「みもり うめ 朝の雑談配信」、日時は 11 月 3 日 8 時から、URL は https://www.youtube.com/watch?v=xxxx。
> サムネイル画像を添付するので、アイキャッチにして。種類は「イベント・出演」。下書きで保存して、プレビューの URL を教えて。

AI がやること: 本文の下書き → 画像をメディアに登録 → お知らせの作成（下書き）→ 種類の設定 → プレビュー URL を返す。
人がやること: プレビューを見て、管理画面で「公開」を押す（または「11/1 の 18 時に予約公開して」と頼む）。

### 予約投稿

> さっきのお知らせを、11 月 1 日 18 時（日本時間）に予約公開して。

予約公開は 1 分ごとの定期処理（Cron）で反映されます。公開まで最大 15 分ほどかかることがあります。

### メンバーの情報を更新する

> 胡蝶くろののひとことを「〇〇〇〇」に変えて。YouTube の URL は https://www.youtube.com/@xxxx。下書きで。

> 新しいメンバーを追加したい。名前は「〇〇」、テーマは「〇〇」、イメージカラーは #6a8fd1、表示順は 60。
> 立ち絵を添付するので、立ち絵画像に登録して。紹介文は 60 字くらいでまとめて、下書きで保存して。

### 会社概要を直す

> 会社概要の表の「所在地」を「〇〇県〇〇市…」に、「設立」を「20XX 年 X 月」にして。下書きで。

### トップページの構成を変える

> トップページの「よくあるご質問」に、「グッズはどこで買えますか？」という質問を追加して。答えは「〇〇」。

> トップページで「活動」と「発信で大切にしていること」の順番を入れ替えて。

### お問い合わせフォームを作る

フォームは公式のフォームプラグインで作ります。

1. 管理画面の左メニュー「Forms」でフォームを作る（項目の例: お名前・会社名・メールアドレス・ご相談の種類・内容）
2. 通知先のメールアドレスを設定する（メール送信の設定が必要。未設定なら管理画面の「Submissions」で受信内容を見る）
3. AI に「お問い合わせページに、さっき作ったフォームを埋め込んで。メールのカードは消して」と頼む

### 新しい種類のコンテンツを足す（元資料のデモ②にあたるもの）

例:「実績」「二次創作ガイドライン・素材ダウンロード」など。

> 「実績」というカスタム投稿を追加して。項目はタイトル・時期・取引先（任意）・概要・画像・リンク。
> /works に一覧ページ、/works/<slug> に個別ページを作って、トップページにも最新 3 件を出すブロックを足して。

型（スキーマ）の追加は MCP でもできますが、表示用のページを作るにはコードの変更が必要です。
この頼みごとは **PC の Claude Code** で、このフォルダを開いて行います（変更は git で commit してから `npm run deploy`）。

## 3. 守ること

- **医療・健康の断定をしない**: 「治る」「効く」などの言い切りは書かない・書かせない（あっぷるぐみの発信方針と同じ）
- **個人情報を載せない**: 依頼者の氏名・連絡先、関係者の個人情報はサイトにも AI への指示にも入れない
- **画像の権利を確かめる**: 立ち絵・サムネイルは使ってよいものだけを渡す
- **消すときはゴミ箱へ**: 削除はまずゴミ箱（復元できる）。完全削除は人が管理画面で行う
- **公開前に人が見る**: AI に「公開して」と頼むのは、プレビューを確認したあとだけ

## 4. 困ったとき

| 症状 | 確認すること |
|---|---|
| AI が「ログインが必要」と言う | コネクタの接続をやり直す（パスキーでログインし直す） |
| 予約したお知らせが公開されない | PC で `npx emdash doctor` と `npx wrangler tail` を実行し、定期処理が動いているか見る |
| 表示が崩れた・ページが真っ白 | 直前にコードを変えたなら、Claude Code に「直前の変更を戻して」と頼み、`npm run deploy` |
| 管理画面に入れない | 別の端末に登録したパスキーで入る。どの端末でも入れなくなると復旧が大変なので、パスキーは 2 台以上に登録しておく |

EmDash を触ってみたいだけなら、公式サイトの Playground（オンラインのお試し環境）で管理画面を体験できます。
